# NISQA whole-recording quality study, v1

September 27, 2026. Pre-outcome protocol for one supervised quality-regression study. This protocol is recorded before selecting the new 200 identities, accessing their numeric targets, acquiring their audio or fitting/inferencing the model. Exact source/input/runtime declarations and independent source review are required before each execution scope. This document is a scientific specification, not evidence of execution or improvement.

The overall goal remains better pronunciation research for ages 6–12 across 23 consonants. This study tests a different, potentially useful recording-quality signal using real human quality ratings. It does not supply child articulation, produced-phone, capture-usability or nonspeech ground truth. Existing pronunciation candidates and learner behavior remain unchanged. Before any new outcomes, [Opus 5.5's independent review](../../work/nisqa-quality-20260927/opus-method-review.json) required a capture-condition control and a target-free input-extrapolation rule; both amendments below precede the new sample. The [original reviewed text](../../work/nisqa-quality-20260927/protocol-before-opus-amendment.md) and blocked receipt are preserved.

## Blind sample and reservations

Reconstruct the complete 1,020-row validated opaque eligibility inventory. Build connected components over **all rows before pilot exclusion**, linking shared `readerGroup`, exact `sourceReferenceID` or `bookCode`. A component ID is SHA-256 of canonical JSON containing sorted distinct membership sets for those three fields; canonical JSON uses sorted keys, compact separators and rejects nonfinite numbers.

Exclude the complete transitive component closure touching any group, exact reference or book in the previously inspected 20-record pilot. Metadata-only inventory shows 421 remaining components/987 rows, including 408 supporting both captures and 13 supporting Skype only. Keep all remaining components eligible, including books containing multiple nominal groups. Do not restrict to single-group books or choose by duration, amplitude or target values.

Choose exactly 200 distinct components, one recording from one nominal group per component, with 100 phone and 100 Skype recordings. Use salt `cadence-nisqa-quality-200-v1`. Hash UTF-8 `salt + NUL + namespace + NUL + value`, with namespaces `component`, `group`, `file`, `partition`; ties use canonical ID/path order.

1. Assign phone, then Skype. For each condition, order its supporting components with condition-exclusive components first, followed by shared components; within each category use component hash then component ID. Select the first 100 unused components. Check both condition support and union feasibility; fail rather than cutting provenance groups or replacing identities.
2. Within each condition's selected 100, order by partition hash of component ID then ID. First 60 are `fit`, next 20 `selection`, last 20 `confirmation`.
3. Within each assigned component/condition, choose nominal group by group hash then ID; choose a file within that group/condition by file hash then path. Preserve the complete original identity row, component ID, partition and canonical identity hash.

This yields 120 fit, 40 selection and 40 confirmation rows, balanced 60/60, 20/20, 20/20 respectively. Reserve **every member and provenance code of each chosen component** to its assigned partition, including unselected members. No group/book/reference/component can bridge partitions. Store the full graph, pilot closure, all exclusions, reservations, counts and selected directory joins. Exactly 40 distinct nominal components support confirmation; the grouping still does not establish verified participant independence.

## Input features and encoder

Use `microsoft/wavlm-base-plus` revision `4c66d4806a428f2e922ccfa1a962776e232d487b`, width 768, final hidden layer only. Bind exact config/preprocessor/377,617,425-byte weight hashes inherited from `encoders.py` and the existing license evidence. This retains the private engineering scope of the model's CC-BY-SA-3.0 terms; do not confuse them with the separate code license or redistribute/promote the model under an unsupported license.

Preserve original-channel raw descriptors in this exact order: RMS, peak absolute amplitude, exact-zero fraction, absolute-amplitude-at-most-1e-4 fraction, digital-rail fraction, duration. PCM rail uses the auditor's valid-bit integer rails; IEEE float uses absolute amplitude at least one as a digital diagnostic, not proof of clipping. Compute all six over every original channel/frame, before downmix/resampling; no gain normalization.

Downmix by arithmetic channel mean in float64. Accepted original rates are 8,000/16,000/22,050/24,000/32,000/44,100/48,000/96,000 Hz; unsupported selected rates fail without replacement. For non-16k rates use pinned SciPy 1.17.1 `signal.resample_poly`, gcd-reduced up/down to 16k, Kaiser window beta 5.0, constant zero padding, float64 computation then little-endian float32 cast. Output length is ceil(original frames × 16000 / original rate). For 16k, copy and cast without interpolation. Retain original-mono float64, resampled float64 and final float32 hashes; no clipping/trimming/gain changes. Synthetic checks must verify format/hash parity, DC/impulse/output length, passband preservation and antialias stopband behavior.

Processor settings remain `do_normalize=False`, `return_attention_mask=True`, 16k, no padding, one clip per forward. Evaluation mode, gradients off, float32, eager attention, CUDA TF32 disabled; no mixed precision, batching-induced padding, crops, layer search or augmentation. Pin Python/NumPy/SciPy/Torch/Transformers/backend/runtime before actual inference. Pool all valid final-layer frames: mean768 followed by population standard deviation768 (`ddof=0`), float64 accumulation then float32. Cache all 1,536 features and six scalars keyed by waveform/model/recipe hashes; no target dependency.

## Fitting and controls

Use float64 analytic fitting with no optimizer/epoch/seed search. Deterministic NumPy linear algebra runs with one BLAS/OpenMP thread; record actual libraries/runtime. Fit SSL population-mean/std scaling on fit rows only. Exactly constant columns save scale one and map to zero **in every partition**. Save the standardized fit minimum/maximum of every column. For non-fit rows, clamp standardized feature values to those saved fit bounds and report per-row/per-column clamp counts; never derive bounds from selection or confirmation. This target-free rule prevents sparse fractions or extreme hidden values from dominating through extrapolation. Original waveforms, raw descriptors and predicted scores remain unclipped.

Fit 16-component PCA by compact SVD on those standardized fit SSL rows, without eigenvalue division at the projection step; fail if numerical rank is below 16. Rank tolerance is `max(matrix.shape) * float64_epsilon * largest_singular_value`. Fix each retained component's sign by making its first maximum-absolute loading nonnegative. Save means/scales/singular values/components/rank diagnostics. Transform selection using the saved bounded SSL scaling and PCA without refitting.

Append the six raw scalars to PCA16; fit population standardization of the resulting 22 columns on fit rows only, with the same all-partition constant-zero and fit-range clamp rules and diagnostics. Scaling the PC scores to unit population variance intentionally gives them equal ridge penalty scale (effective whitening), despite no eigenvalue division in the PCA projection itself. Acoustic control uses only the same six raw scalars with identical fit-only standardization/bounding. Pooled mean control predicts each dimension's fit mean. The additional capture-condition mean control predicts each dimension's **phone or Skype fit mean**, using only the known capture metadata; it tests whether apparent quality learning merely identifies capture condition.

Fit one five-output ridge candidate and one acoustic-only ridge control. For n rows and five targets, the objective is `sum((Y - intercept - X @ B)^2) / (5*n) + lambda * sum(B^2)`, with an unpenalized intercept. Center inputs and targets; solve with penalty `5*n*lambda`, and preserve finite/rank/solver diagnostics. Only lambda values `{0.01, 0.1, 1, 10}` are allowed. Select one common lambda for all five outputs in each model by equal-weight five-dimension selection MAE; larger lambda wins exact ties. Retain every grid result and predictions. Outputs are unbounded; no clipping, post-hoc logistic mapping or score rescaling.

Freeze the selected lambda recipes. Refit each model's scaling/PCA/regression and input bounds on all 160 fit+selection rows, and recompute both pooled and capture-specific mean controls on the same 160. Predict the 40 confirmation rows once for all four models and freeze models plus predictions before confirmation targets. Never fit PCA/standardization/bounds on all 200. A successful simpler acoustic control is reported as that prespecified control's result, not an SSL success.

## Confirmation endpoints and continuation screen

Primary endpoint is equal-weight macro MAE across five dimensions, using the same 40 rows for all models. Report each dimension's MAE/RMSE, macro RMSE, individual paired errors/differences and separate phone/Skype counts and errors. Secondary Pearson correlations preserve undefined constant cases as null; no fitted mapping.

For candidate-versus-each-of-three-controls macro-MAE differences, resample whole nominal components with replacement in paired fashion. This sample has one chosen recording per component. Use NumPy `Generator(PCG64(27092026))`, 10,000 unstratified draws, each of 40 components; retain the common index-draw hash. This estimates the empirical mixed-capture population rather than conditioning on fixed bootstrap capture quotas. Percentile 95% intervals use quantiles 0.025/0.975 with linear interpolation. Negative differences favor the candidate. Report finite-sample and imperfect-code limitations.

The fixed research continuation screen requires **all**: candidate macro MAE at least 0.05 MOS lower than each of acoustic ridge, pooled mean and capture-condition mean; upper endpoint of all three paired 95% intervals below zero; no dimension more than 0.10 MOS worse than pooled mean control; and both capture subsets' macro-MAE differences versus capture-condition mean nonpositive. These are research screening margins, not clinically validated importance thresholds. Failure or wide intervals do not authorize tuning on confirmation. Passing warrants untouched-sample replication and child-domain investigation; it does not promote a learner/clinical candidate.
