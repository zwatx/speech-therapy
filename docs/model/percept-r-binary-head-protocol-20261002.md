# PERCEPT-R development binary /r/ head — protocol

Status: pre-training revision 3. A new local, noncommercial development experiment, separate from the closed external check. No new candidate has been fitted. Review fixes are allowed before declaration; after declaration protocol and scientific source are immutable. No sealed TEST access, deployment, redistribution or clinical claim.

## Question and evidence limits

Can a small /r/ specialist trained on PERCEPT-R listener counts improve the retained model's ranking of derhotic words **within a child**? The old pooled DEV AUROC is 0.781920 but within-child median is 0.605405. DEV outcomes have already informed this choice. Nested child-disjoint validation gives development evidence, not a fresh confirmatory test. Neither the 80-child TEST partition nor the original rating archive will be opened. This cannot establish performance on the other 22 targets, clinical categories, unfamiliar corpora or unsupported recording conditions. Canonical-prompt features and embeddings may encode word identity: a within-child gain can partly reflect word difficulty, and does not isolate acoustic quality.

## Child-disjoint nested validation

Five outer folds. Rank numeric child IDs by SHA256 of UTF-8 `percept-r-binary-head-20261002:outer:<id>` (hash then ID tie break), assign rank modulo 5. For each outer fold f, split its fitting children into four inner folds using salt `percept-r-binary-head-20261002:inner:<f>:<id>` with the same rule. Assign every token by child, save the full manifest before training, and require disjoint/complete fit/validation/test memberships.

Outer held-out labels may be used only for final evaluation after all outer predictions and all three controls are saved/hash locked in one artifact. Fit transformations and hyperparameter selection only on outer fitting children. Inner fitting transformations cannot use inner validation features or labels. Before training, freeze childToStudies (sorted study strings per numeric child) and studyChildCounts from saved per-token records.study. Require at least two distinct studies and at least one remaining child for every whole-child study omission. Folds are fixed irrespective of outcome. No model-family or seed selection after results.

## Candidate and controls

Candidate: ridge binomial logistic regression with 30 standardized columns: 16 embedding PCA coordinates, 13 raw scalar features, and retained-score logit. Clip retained probabilities to [1e-6,1-1e-6] **only for input logit**; the unchanged ranking control uses the original score.

For every inner and outer fit: embedding mean and population covariance are calculated from fitting rows only in float64; symmetric eigh, descending eigenvalues; 16 unscaled PCA components initially; subsequent fitting-column standardization scales these coordinates by their fitting standard deviations, equivalent to whitening them for the logistic fit. Largest absolute loading coordinate has positive sign (first index breaks ties). Require eigenvalue16 > 1e-12 * max(1,largest eigenvalue). Project and concatenate in float64. Column mean/population standard deviation use fitting rows only; std<1e-6 becomes 1. PCA and moments are unweighted row quantities. No held-out transform fitting. Numeric environment and thread settings are recorded.

Fit loss uses weights w_i = n_i / sum(n_j for fitting tokens of child_i), divided by number of fitting children. Thus weights sum to 1 and each child contributes equally. Objective is sum(w_i * [logaddexp(0,z_i)-y_i*z_i]) + lambda/2 * ||beta||²; intercept unpenalized. Initialize all coefficients to zero and intercept to logit of the fitting weighted target mean clipped to [1e-6,1-1e-6]. Damped Newton with exact analytic Hessian, SciPy Cholesky solve, float64. At each iteration accept only when analytic gradient infinity norm <=1e-8; otherwise solve Hessian times direction = negative gradient and use Armijo backtracking from step 1, factor 0.5, coefficient 1e-4, maximum 50 backtracking steps, maximum 100 Newton steps, with the gradient test also performed after step100. A trial is accepted if Armijo holds, or if trial objective <= old objective + 16*float64_eps*max(1,abs(old objective)) AND trial gradient infinity norm is strictly below the old norm. Record which condition accepted every step. This roundoff safeguard does not relax the final 1e-8 stationarity gate. All outputs must be finite; any failed Hessian/line search or exhausted iteration budget closes the attempt as failed. No silent retries or changed settings. Save iteration/line-search diagnostics, final objective and gradient norm; audit recomputes stationarity.

Choose lambda from [0.0001,0.001,0.01,0.1]. For each lambda, average the four inner held-out speaker-balanced unpenalized log losses (each fold's children equally weighted within fold). Choose lowest mean, ties within 1e-10 choose larger lambda. Refit one candidate on the entire outer fitting set. PCA/moments may be reused across lambdas only for identical fitting row membership. Save all 80 inner fits, validation predictions/losses and five outer fits/OOF predictions for audit.

Controls on each outer fitting set: (1) unchanged immutable retained p0+p1; (2) fitting weighted target prior; (3) monotonic retained-logit logistic calibration, fitted with its own fitting logit mean/std and the same objective/optimizer, fixed lambda=0.001, slope constrained >=0. Solve the unconstrained one-slope problem with the same Newton routine; if slope is negative, the exact constrained optimum is slope zero and intercept logit of the fitting weighted target mean. Require projected gradient infinity norm <=1e-8 (at slope zero replace slope gradient by min(gradient,0)). Save unconstrained solution and boundary decision. Every fitting set must contain positive and negative votes, otherwise fail. No calibration hyperparameter search. None of these controls selects a candidate family or rescues a failed result.

## Evaluation and fixed development screen

Positive votes=n-k, negative votes=k. Vote-weighted AUROC includes a token's own positive/negative vote pair as a half-weight tie and counts all tied scores as half; AP groups ties. Primary is unweighted mean of per-child vote-weighted AUROC, paired candidate minus unchanged retained. Undefined per-child AUROCs are listed and cause the screen to fail; never silently dropped. Report median, all per-child values and number improved. Prior and calibration controls are also reported.

Use NumPy default_rng(20261002), with one rng.integers(0,119,size=(2000,119)) draw over lexicographically sorted child IDs, for 2,000 paired whole-child bootstrap replicates, resampling the 119 saved per-child OOF values with replacement. Report percentile 95% paired gain interval using linear quantiles and paired child deletion gains (remove one child from the macro mean). Child deletion gains are descriptive and are not a screen gate (redundant with a 0.02 mean gain for119 children). This conditions on saved OOF fits and does not capture model refitting, fold dependence or study-level uncertainty. It is a development screen, not confirmatory significance.

Screen passes only if all hold: mean within-child candidate-minus-retained AUROC gain >=0.02; bootstrap lower gain >0; leave-one-study-out within-child macro gain >0 for every study (remove every child with any token in that study from the saved child gain vector, including their other-study tokens, using saved records.study and the frozen childToStudies map; average remaining saved per-child OOF gains without refitting); pooled candidate vote-weighted AUROC >= retained pooled AUROC-0.01; candidate speaker-balanced binomial log loss <= monotonic calibration control's speaker-balanced log loss. Candidate loss and baseline comparisons use all saved OOF predictions, weighting children equally and votes within child. Evaluation probabilities clipped [1e-12,1-1e-12] for logarithms only. Expected per-vote Brier = y*(1-p)^2+(1-y)*p^2 with the same weights. Also report pooled vote-weighted AP, Spearman with per-token y, per-child values and descriptive study/context/age/PRE vs other phase breakdowns. Report within-child retained-score tie fractions (fraction of unordered distinct token pairs with exactly equal scores; null for a single-token child) and selected lambdas at grid boundaries. No outcome-driven subgroup exclusion or additional experiments.

If this final fit fails after a passed screen, retain/report the screen result and the failure, make no completed export and never silently retry. Export safe NPZ numeric arrays and JSON metadata, R-only binary derhotic/rhotic probabilities, target definition and limitations.
