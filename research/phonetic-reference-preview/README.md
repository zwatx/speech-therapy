# Inactive desktop reference preview V2

Source-only operational adapter for the original Hugging Face Wav2Vec2ForCTC phonetic checkpoint, revision ae45363bf3413b374fecd9dc8bc1df0e24c3b7f4. It is not connected to any application, browser route or server. Importing sources and constructing an owner reads no assets and starts no subprocess. `frozen-v1/` preserves the incomplete initial adapter; the unchanged original `SOURCE-v1.json` describes that frozen version, not current V2 sources.

Four functional files:

- `contract.py`: closed acoustic request, result/artifact/timing schema, strict canonical whole mono 16000 Hz PCM16 RIFF admission with 1600–64000 samples, valid-frame CTC, vocabulary/special-symbol metadata and private loading metadata checks.
- `worker.py`: pinned NumPy extractor, unchanged CPU FP32 model forward, strict loading info and exactly the two positional weight-norm migrations; durable invocation-committed receipt before forward; private finite full logits and normalized arrays plus hypothesis/loading JSON; closed failures without exception text.
- `owner.py`: explicit root activation and entrypoint, complete runtime prehash and exact five snapshot-link/blob mapping, verified source-buffer compile in a fresh `-I -S -B` interpreter, one cold subprocess, cancellation/deadline/identity-tracked descendant cleanup and bounded join. This contains rebound source from the pinned mobile process helper with explicit join/metrics changes. No old guard or service is invoked.
- `test_reference_preview.py`: pure source, metadata and lifecycle mocks. No WAV generated/read, framework imported or actual subprocess started.

Root first loads this owner from independently verified bytes, supplies the exact reviewed source/bindings hashes and a separately reviewed execution-job hash, and provides an explicit admission whose hash is itself independently bound. `root_entrypoint` performs actual preflight and input read only after that admission. No admission or active future-job manifest is supplied here. The inactive source and binding manifests are provenance, not execution permission. Expected hashes must come from root review; accepting hashes from a UI is unsafe.

The owner stages one private 0700 directory and exclusive 0600 input/evidence/artifact files. Cancelling invalidates presentation immediately while exact cleanup still owns resources. Unknown cleanup or a replaced borrowed input retains the borrow and blocks another attempt. A successful owner handles exactly one request. Private hypotheses/IDs, logits and normalized values are sensitive speech information. Public reports should use typed status/counts and artifact identities only. Artifact files stay private for separately authorized engineering collection.

`model_call_state=invocation_committed` means the durable intent marker was written immediately before calling forward; it does not prove forward completed. `completed` requires a valid completed response. Exceptional ownership failures can yield `unknown` and `model_called:null`; uncertainty is never silently counted as a completed call. Cleanup status is based on exact child/descendant observations, independent of worker response. The pending job must count committed/unknown/completed separately.

The fixed offline environment and socket/process audit denials are application controls, not OS network isolation or adversarial containment. Actual account HOME is retained. Runtime preflight verifies 27713 manifest rows, 27695 inventory names, 31 RECORD paths and the pinned interpreter before startup. Model weight identity in bindings is inherited here; only the root entrypoint actually rehashes weight bytes. Standard-library/system runtime coverage and platform-dependent cleanup behavior require independent root review before execution.
