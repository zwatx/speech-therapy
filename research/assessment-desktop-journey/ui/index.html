    About this build

    This is an engineering prototype for development. It gives no scores, diagnoses, correctness feedback or progress measures, and it is not for clinical or production use.

    Example recordings are existing public recordings shared under their own licenses. The author, license, source and any changes for each one are listed beside the player. Playback uses copies held by this build's server. Speaker ages are not known. Pictures are original artwork made for this project.

    Private checks run the research model on existing example recordings only. They never use a microphone or capture anyone's speech. A completed check means the research processing finished; it is not a finding about a word or a speaker. Replay checks reuse the same recording to test that processing is repeatable.

    The words and wording have had engineering review only. Professional review is deferred until the finished product.
